# Admin user directory

Mode: Operate. A private, read-only surface for the AgentUI owner to find registered users and copy an email address without exposing authentication secrets.

## Direction contract

THESIS: A calm user ledger built for quick verification; refuse the generic analytics dashboard and ornamental metric-card grid.

OWN-WORLD: AgentUI's Geist typography, near-white/charcoal surfaces, quiet hairlines, compact controls, and semantic success/warning color only where status requires it.

STORY: Authenticate, scan the total and filters, find a person, inspect safe identity details, copy the email, and leave.

FIRST VIEWPORT: A narrow title row, one compact total, search and provider filter, then the user table; primary action is search, with sign-out kept secondary.

FORM: Code-first, compact responsive directory extending the established site shell; selected in the approved implementation plan.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Unresolved decisions: none.
