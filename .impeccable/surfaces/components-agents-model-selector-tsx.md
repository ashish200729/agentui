## Direction contract

THESIS: Model and effort choice should feel like one calm composer action, not a settings form; refuse a generic detached menu or a speed control.

OWN-WORLD: AgentUI semantic neutrals, 16px panel corners, compact Geist typography, a single accent trace, and quiet depth through border plus motion rather than ornament.

STORY: The developer opens effort management first, adjusts reasoning depth, then enters the full model list through the current model name without leaving the composer.

FIRST VIEWPORT: A compact model-and-effort pill sits inside a restrained composer. Its panel opens upward into a stable discrete effort slider; the current model switches the same anchored surface to the complete model list.

FORM: Precisely specified local extension; no concept seed. Signature interaction is a plain anchored view switch whose bottom edge never moves, plus a spring-gliding effort thumb and model row.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
